# Maple Logistics - US Supply Chain Profitability Analysis | Excel

![Dashboard](Maple_Logistics_Report_Dashboard.png)

## 📦 Overview
Analyzed 8,001 orders for a US logistics company (2012-2014) to identify profit leaks and growth opportunities.
Built entirely in Microsoft Excel.

**Key Metrics:**
- Sales: $1,812,853
- Profit: $236,853
- Margin: 13.06%
- Total Orders: 8,001

## 🔍 Key Insights

1. **18.6% orders are losing money** - Root cause: Discount >20%
2. **Profit Growth:** 51.8% growth from 2012 ($61K) to 2014 ($93K) - 2014 contributed 39.48% of total profit
3. **Category:** Technology = Highest Avg Profit, Furniture = Lowest ($7.6)
4. **State:** California ($63K) most profitable, Arizona at net loss - needs logistics audit
5. **Shipping:** Standard Class drives 57% of total profit

## 💡 Recommendations

- Cap discount at 20% max, remove discount from Tables category (45% discount = net loss)
- Make Standard Class default shipping to save cost
- Re-route Arizona fulfillment via California hub
- Prioritize stock for Phones, Chairs, Copiers (high profit SKUs)
- Prepare inventory for March peak season
